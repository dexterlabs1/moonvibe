Moonvibe

Flatpak repository for Moonvibe, a Deck-first game-streaming client.

Install on a Steam Deck

In Desktop Mode, open moonvibe.flatpakref. Discover installs it and every later version shows up in Discover’s update list.

Or from a terminal

flatpak install --user https://dexterlabs1.github.io/moonvibe/moonvibe.flatpakref
